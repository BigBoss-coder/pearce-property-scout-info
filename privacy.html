Pearce Property Scout privacy notice

Last updated: October 27, 2026

Purpose and access

Pearce Property Scout is a personal-use automation operated by its account owner. It requests https://www.googleapis.com/auth/gmail.readonly. This permission allows reading the authorized Gmail mailbox, including messages and settings. The program verifies the connected mailbox and retrieves only recent listing alerts matching the configured BAREIS sender and subject. It does not request permission to send, modify, label, or delete mail.

Use and sharing

GitHub Actions runs the program within a private application repository and processes the matching emails. The program extracts listing facts such as the MLS number, property address, price, status, market days, and basic property features.

Extracted property facts and the owner's screening criteria are sent to the OpenAI API for prioritization. The program excludes email headers, contact details, full email bodies, report access links, and credentials from that AI request, and sets store: false on the Responses API request. Provider retention and processing remain subject to the provider's applicable policies.

A short digest, including selected property facts and listing report links, is sent through the configured Telegram bot to a private group selected by the owner. Group members can view and retain these messages. The program does not sell Gmail data or use it for advertising.

Storage

The Gmail OAuth credential, OpenAI API key, and Telegram configuration are stored as encrypted GitHub Actions secrets. People or workflows with sufficient access to the application repository may be able to use these secrets. The private repository stores processed email identifiers, listing fingerprints, and run timestamps to avoid repeated alerts. This state may also remain in git history.

Requested previews may be saved as private GitHub Actions artifacts with a one-day retention setting. Local previews remain on the owner's computer until removed. Run logs are limited to operational status and aggregate usage, rather than full listing digests. GitHub, Google, OpenAI, and Telegram each apply their own service retention and security policies.

Owner controls

The owner can stop scheduled runs, remove repository secrets and stored results, delete Telegram messages, and revoke the app's access at Google Account connections. Revoking Google access prevents further Gmail API access with that grant; it does not recall previously delivered messages or delete provider backups.

This notice describes the current personal-use automation. A change to its purpose, recipients, requested permissions, or data handling requires reviewing and updating this notice before the new behavior is enabled.
