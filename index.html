Pearce Property Scout

Pearce Property Scout is a personal-use tool that screens real estate listing alerts from Gmail and delivers a short property-review digest to a private Telegram group. It is operated by its account owner and has no public signup.

The tool runs in a private GitHub repository. It reads matching BAREIS listing emails using Google's read-only Gmail permission, extracts property facts, and uses the OpenAI API to help prioritize listings against the owner's criteria. It does not send, edit, label, or delete Gmail messages.

The digest is an initial screening aid. It does not verify property condition, title, comparable sales, renovation costs, or investment returns.

See the privacy notice for access, storage, and sharing details.

This public information repository contains documentation only. Application code, mailbox data, property results, and credentials belong in the separate private application repository.
